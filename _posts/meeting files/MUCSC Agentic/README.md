# MUCSC Agentic Lab Resources

This folder contains the resources for the Miami University Cybersecurity Club's AI Agentic Lab. These materials introduce members to locally hosted AI models, large language models (LLMs), and building their first AI agents using Python and Ollama.

## Files

- **First Agent Lab Install Guide:** Instructions for installing Ollama, downloading the Llama 3.2 model, and setting up Python.
- **First Agent Lab Clean Up Guide:** Instructions for removing the AI model or uninstalling Ollama after the lab.
- **Password Coach Starter:** Starter code for building an AI-powered password coaching agent.
- **Password Coach Clean:** A completed example of the password coaching agent.
- **Decoder Starter:** Starter code for building an agent that decodes Base64, hexadecimal, and ROT13 text.

Use made-up passwords when testing the password coach. Never enter real passwords.
